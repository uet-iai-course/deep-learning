# Tài liệu nguồn

- `slides/`: slide chính cần chuyển.
- `textbooks/`: textbook hoặc chương sách dùng để đối chiếu.
- `papers/`: paper dùng để sửa hoặc kiểm chứng mệnh đề.
- `resources/`: code, dữ liệu, hình và tài sản liên quan.

Nội dung trong các thư mục con bị `.gitignore` bỏ qua theo mặc định để tránh vô tình commit textbook, dữ liệu lớn hoặc tài liệu có giới hạn phân phối. Có thể điều chỉnh `.gitignore` khi thực sự cần quản lý phiên bản một tài sản cụ thể.

Bỏ qua `.DS_Store`, tệp `._*` và tệp tạm `~$*` khi kiểm kê.
